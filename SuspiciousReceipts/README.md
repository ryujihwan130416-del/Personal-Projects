# 수상한 영수증

한빛지방국세청 조사관이 되어, 영수증과 지출내역서만 대조하는 1인 추리 게임입니다. 브라우저에서 바로 열립니다.

한 조사를 서류를 읽으며 끝까지 진행하면 약 40분에서 한 시간입니다. 처음 철은 연습 전표이고, 그다음 여섯 철이 순서대로 열립니다. 철을 닫을 때마다 컷이 재생됩니다. 맞으면 빈 의자와 소환 도장이 남고, 보고서가 틀리면 그 서류의 사실을 보여주는 다른 컷이 나옵니다. 책상의 힌트는 과장 메모를 한 줄씩 꺼냅니다. 마지막 의견서에서 결말이 갈라지고, 결말마다 업적이 남습니다.

## 여는 법

`index.html`을 더블클릭하거나 브라우저로 엽니다. `file://`에서도 동작합니다. 서버, 설치, 외부 요청은 없습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| J / K | 서류 목록 이동 |
| Enter | 서류 열기 |
| C | 대조에 올리기 (최대 3장) |
| F | 지적 올리기 |
| B | 수첩에 남기기 |
| N | 수첩 |
| M | 매뉴얼 |
| R | 보고서 또는 의견서 |
| Esc | 닫기, 한 번 더 누르면 철로. 컷에서는 건너뛰기 |
| Enter | 컷에서는 다음 장면 |

규칙은 게임 안 매뉴얼에 있습니다. 현실 세법 지식은 쓰지 않습니다.

## 저장

- 자동 저장 키: `suspiciousReceipts.v1`
- 슬롯 3칸: `suspiciousReceipts.slots.v1`
- 업적: `suspiciousReceipts.achievements.v1` (조사를 지워도 업적은 남습니다)
- 저장 화면에서 JSON 파일로 내보내거나 불러올 수 있습니다.

## 컷

새 조사의 착수, 연습 전표를 포함한 각 철을 닫은 직후, 마지막 철을 처음 열 때, 그리고 의견서를 마감한 뒤에 컷이 재생됩니다. 글은 컷 다음의 종결 메모에 남습니다. 표지의 착수 컷, 에필로그의 컷 다시 보기로 다시 볼 수 있습니다.

## 결말

마지막 철의 의견서는 모은 지적에 따라 갈립니다. 결재만, 사업자까지, 항만의 이니셜까지, 선택 서류까지 모은 특별조사, 보류, 그리고 다른 이름을 정점으로 적은 오판. 에필로그에서 의견서만 다시 쓸 수 있습니다.
