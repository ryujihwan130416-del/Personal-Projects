# 클라우드 아레나

Scratch 클라우드 변수로 맞붙는 2인 탑다운 슈터입니다. 완성 파일은 `cloud-arena.sb3`입니다.

## 플레이

1. [scratch.mit.edu](https://scratch.mit.edu)에 **스크래처** 계정으로 로그인합니다. 뉴 스크래처는 클라우드 변수를 쓸 수 없습니다.
2. `cloud-arena.sb3`를 업로드합니다.
3. 두 사람이 같은 프로젝트 페이지에서 초록 깃발을 누릅니다.
4. 한 명은 초록 **방 만들기**(또는 `1`)를 누릅니다. 위에 방 번호가 나옵니다.
5. 다른 한 명은 파랑 **참가**(또는 `2`)로 그 번호를 입력합니다.
6. WASD 또는 방향키로 이동하고, 마우스로 조준하고, 스페이스로 발사합니다.
7. 3발을 맞으면 쓰러집니다. 먼저 5킬을 하면 이깁니다. 빨강 **나가기**(또는 `0`)로 방을 비웁니다.

클라우드 변수는 스크래치 사이트에서만 서로 연결됩니다. 에디터에서 파일만 열면 조작은 되지만 상대와 이어지지 않습니다. 변수는 프로젝트 전체에서 공유되므로, 동시에 안정적으로 붙는 방은 하나뿐입니다.

## 다시 만들기

```bash
python3 CloudArena/make_sb3.py
```
