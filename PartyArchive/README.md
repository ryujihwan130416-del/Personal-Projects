# 파티 아카이브

한 키보드로 즐기는 2인 파티 미니게임 모음집입니다.

## 실행 방법

1. `PartyArchive/index.html`을 브라우저에서 엽니다 (더블클릭 / `file://` 가능).
2. 로컬 서버나 빌드 도구는 필요 없습니다.

## 조작

| 역할 | 키 |
|------|-----|
| P1 주행동 | `A` |
| P1 보조 | `S` (버티기·열 선택·교차 입력 등) |
| P1 특수 | `Q` (조심 펌프·색 패스 등) |
| P1 이동 (링 아웃) | `W` `A` `S` `D` |
| P2 주행동 | `L` |
| P2 보조 | `K` |
| P2 특수 | `O` |
| P2 이동 (링 아웃) | `↑` `←` `↓` `→` |
| 시작 / 다시하기 | `Space` |
| 로비 (토너먼트 중단) | `Esc` |

## 미니게임 (손맛별)

| 게임 | 코어 루프 |
|------|-----------|
| 줄다리기 | 연타 + 버티기 |
| 눈치 대결 | 반응 속도 |
| 폭탄 돌리기 | 전달 / 슬램 |
| 타이밍 스톱 | 존에서 정지 |
| 두더지 쟁탈 | 열 선택 + 타격 |
| 풍선 펌프 | 위험 펌프 (랜덤 폭발) |
| 색 신호 | 색 판정 + 금지 패스 |
| 비트 탭 | 리듬 |
| 사다리 오르기 | 교차 연타 |
| 링 아웃 | WASD vs 화살표 피지컬 |

## 모드

- 사람 vs 사람 / 사람 vs AI (쉬움·보통·어려움)
- 랜덤 한 판 / 파티 토너먼트
- prefs: `partyArchive.prefs.v1` · 점수: `partyArchive.scores.v1`

## 제약

HTML / CSS / Vanilla JS만. npm·CDN·외부 이미지·mp3 없음. Web Audio로 짧은 효과음만 생성.
