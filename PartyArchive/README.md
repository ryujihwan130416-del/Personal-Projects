# 파티 아카이브

한 키보드로 즐기는 2인 파티 미니게임 모음집입니다.

## 실행 방법

1. `PartyArchive/index.html`을 브라우저에서 엽니다 (더블클릭 / `file://` 가능).
2. 로컬 서버나 빌드 도구는 필요 없습니다.

## 조작

| 역할 | 키 |
|------|-----|
| P1 주행동 | `A` |
| P1 보조 (일부 게임) | `S` |
| P2 주행동 | `L` |
| P2 보조 (일부 게임) | `K` |
| 시작 / 다시하기 | `Space` |
| 로비로 (토너먼트 중단) | `Esc` |

보조키를 쓰는 게임: **폭탄 돌리기**, **두더지 쟁탈**, **사다리 오르기**.

## 모드

- **사람 vs 사람** — 한 키보드를 나눠 사용
- **사람 vs AI** — 쉬움 / 보통 / 어려움
- **랜덤 한 판** — 전체 미니게임 중 무작위
- **파티 토너먼트** — 전 게임을 섞어 연속 플레이

모드·난이도·최근 플레이 게임은 `localStorage`(`partyArchive.prefs.v1`)에 저장됩니다. 세션 승수는 `partyArchive.scores.v1`입니다.

## 제약

- HTML / CSS / Vanilla JavaScript만 사용
- npm, 프레임워크, 번들러, CDN, 외부 이미지·mp3 없음
- Web Audio API로 짧은 효과음만 절차적 생성
