당신은 프론트엔드 게임 개발자다. 이미 있는 `PartyArchive/`(로컬 HTML 2인 파티 미니게임)를 **처음부터 만들지 말고** 읽고 정리·개선하라.

# 유지할 것
- 경로 `PartyArchive/`, Vanilla JS only, npm/CDN/외부 에셋 금지, `file://` 동작
- UI 한국어, 닌텐도/마리오 IP 금지
- PvP / vs AI / 난이도 / 세션 점수 / 뮤트 / 랜덤 / 토너먼트 / prefs 유지
- `PROMPT.md` 원문 보존. 이번 작업 프롬프트는 `UPDATE_PROMPT_v16.md`로 저장

# 핵심 목표
1. 키가 너무 단조롭다 — A/L 위주 탈피, 게임마다 손맛 다르게
2. 연타 레이스 복제(줄다리기/퍽/풍선) 정리
3. WASD vs 화살표의 **피지컬 이동** 미니게임 추가
4. 풍선은 **랜덤한 지점에서 터지게** 재설계

# 유사 게임 정리
- `push` 삭제 (파일·로드·카드·CSS)
- `catch` 삭제 (stopbar와 존-스톱 중복) — stopbar 유지
- `tug` 유지 + 보조 입력(버티기 등)으로 순수 연타와 차별
- `balloon` 유지하되 재설계: 각자 풍선에 **숨겨진 랜덤 폭발 임계치**. 연타로 부풀리다 임계치 넘기면 터져 패배. 시간 종료 시 안 터진 쪽 중 더 큰 쪽 승.
- `draw` / `color` 유지하되 color는 색·금지·역할 비대칭으로 확실히 차별

# 키맵
- P1 왼쪽 / P2 오른쪽 분할. 한 사람이 WASD+화살표 동시 사용 금지.
- 피지컬 게임: **P1 = WASD, P2 = 화살표**
- 액션 게임: P1 = Q/A/S (등), P2 = O/K/L (등) — `input.js`에 명확히 정의
- Space 시작/다시하기, Esc 로비
- 홀드 연타(keydown repeat) 차단. 이동은 `isHeld` 폴링 허용.
