당신은 프론트엔드 게임 개발자다. 아래 스펙대로 로컬에서 바로 열리는 2인용 2D 파티 미니게임 아카이브를 처음부터 만들어라.

# 프로젝트
 -새 폴더 만들기
- 기술: HTML, CSS, Vanilla JavaScript만. npm, 프레임워크, 번들러, 외부 CDN, 이미지/오디오 에셋 URL 금지.
- 그래픽은 CSS + Canvas/DOM으로 직접 그린다. 이모지 남용 금지. 보드게임/파티게임 느낌의 원색, 두꺼운 테두리, 큰 타이포.
- 진입점: index.html 을 더블클릭하거나 로컬 서버 없이 열어도 동작해야 한다 (file:// 호환).
- 언어: UI 전부 한국어.
- 저작권: 마리오, 닌텐도 캐릭터/로고/사운드/상표 사용 금지. "마리오파티 같은 리듬감"만 참고한다.

# 제품 콘셉트
한 화면 키보드로 하는 2인 특화 미니게임 모음집.
로비는 보드게임 상자/파티 테이블처럼 보이고, 각 게임은 짧고(20~45초), 승패가 바로 갈리며, 조작이 피지컬적으로 어렵지 않아야 한다.
3인 이상, 솔로 전용, 복잡한 플랫폼/슈팅은 만들지 마라.

# 로비 (index)
필수 화면:
1) 타이틀: "파티 아카이브"
2) 모드: 사람 vs 사람 / 사람 vs AI
3) AI 난이도: 쉬움 / 보통 / 어려움 (vs AI일 때만)
4) 게임 5개 카드 (이름, 한 줄 규칙, 예상 시간, P1/P2 키 안내)
5) 점수판: 세션 승수 (localStorage에 저장). 로비에서 초기화 가능
6) 조작 범례: P1 = A / S (필요 시), P2 = K / L (필요 시), 공통 = Space 시작, Esc 로비

로비에서 카드를 누르면 해당 게임의 준비 화면 → Space로 시작.
게임 종료 후 승자 연출 → 다시하기 / 로비.

# 조작 규칙 (중요)
- 두 사람이 한 맥 키보드를 나눠 쓴다고 가정한다.
- 플레이어당 최대 2키. 동시에 많은 키를 연타하거나 복잡한 콤보는 금지.
- 방향키/WASD 동시 사용처럼 손이 꼬이는 배치는 금지.
- 기본 배치:
  - P1 왼쪽: A (주행동), S (보조, 필요한 게임만)
  - P2 오른쪽: L (주행동), K (보조, 필요한 게임만)
- keydown 반복(키 홀드 연타)은 막는다. 연타 게임은 keyup 후 다시 눌러야 인정.
- vs AI일 때 P2 키는 무시하고 AI가 조작한다. 화면에는 "AI" 라벨.

# 공통 게임 루프
각 게임 모듈은 같은 인터페이스를 가진다:
  init(rootEl, { mode, difficulty, onFinish })
  start()
  destroy()  // 타이머/리스너 전부 해제
- 카운트다운 3-2-1 후 시작
- 상단에 P1/P2 점수 또는 진행 바
- 무승부 가능. 무승부면 점수 없음
- 승리 시 세션 승수 +1
- 접근성: 큰 버튼, 고대비, 포커스 가능한 로비 컨트롤

# AI
js/ai.js 에 난이도 프로파일:
- 쉬움: 반응 220~420ms, 실수율 35%, 타이밍 오차 큼
- 보통: 반응 140~260ms, 실수율 18%
- 어려움: 반응 70~140ms, 실수율 7%, 가끔 완벽에 가까운 타이밍
AI는 사람처럼 보이게 지연/랜덤을 넣고, 매 프레임 완벽한 추적은 하지 마라.
게임별로 "지금 눌러야 하는가"를 콜백으로 받게 만들어 재사용하라.

# 미니게임 5개 (2인 특화만)

## 1. 줄다리기 (tug) — 약 20초
줄 중앙 깃발이 화면 가운데. 각자 주행동 키를 더 많이 누르면 깃발이 자기 쪽으로 이동.
시간 종료 시 자기 진영에 더 가까운 쪽이 승리. 중앙이면 무승부.
연타는 빠르되 홀드 연타는 무효. AI는 난이도별 연타 주기.

## 2. 눈치 대결 (draw) — 1라운드 승부, 최대 3판 2선승
화면에 "대기..." 후 랜덤 1.2~3.5초 뒤 "지금!" 신호.
신호 전 누르면 실격(상대 승). 신호 후 더 빨리 누른 쪽이 승.
오신호(가짜 "잠깐!")를 가끔 넣어 긴장감을 준다. 가짜일 때 누르면 실격.
AI는 신호 전 실수율 + 신호 후 반응지연으로 구현.

## 3. 폭탄 돌리기 (potato) — 약 15~30초
폭탄이 P1↔P2 사이를 들고 있다. 주행동 키로 상대에게 던진다.
제한 시간이 랜덤하게 짧아진 뒤 폭발. 폭발 순간 들고 있는 사람이 패배.
던진 직후 0.25초 쿨다운으로 스팸을 줄인다.
AI는 남은 시간이 짧을수록 던질 확률이 높아지게.

## 4. 타이밍 스톱 (stopbar) — 3라운드 합산
왕복하는 게이지가 목표 존을 지나간다. 주행동 키로 멈춘다.
존 중앙에 가까울수록 고득점(100점 만점). 3라운드 합이 높은 쪽 승.
두 플레이어가 동시에 같은 바를 보는 대결(각자 라운드를 번갈아 하거나, 좌우 분리 바 동시 진행).
동시 진행이 더 파티게임답다. 좌측 바 P1, 우측 바 P2.
AI는 목표 존 진입 후 난이도별 오차로 누른다.

## 5. 두더지 쟁탈 (moles) — 약 25초
3x3 구멍. 두더지가 하나씩(가끔 둘) 올라온다.
두더지가 떴을 때 해당 열이 왼쪽이면 P1만, 오른쪽이면 P2만, 가운데면 둘 다 쟁탈.
주행동 = 자기 쪽 두더지 획득, 가운데는 더 빨리 누른 쪽 획득.
잘못된 타이밍(없는 구멍) 누르면 0.4초 경직.
점수 많은 쪽 승. AI는 자기 열/가운데만 노린다.

# 시각/연출
- 로비: 나무 테이블 + 보드 타일 카드, 주사위/칩 장식(CSS)
- 각 게임 시작/종료 시 짧은 스케일 팝, 화면 흔들림은 과하지 않게
- 모바일 레이아웃은 최소만 (이 프로젝트는 데스크톱 2인 키보드가 본체)
- 60fps 목표. requestAnimationFrame. setInterval 남용 금지
- 사운드는 Web Audio API로 짧은 beep/팝만 절차적 생성. 외부 mp3 금지. 뮤트 토글 제공

# 품질 기준
- 새로고침 없이 로비↔게임 왕복 가능, destroy 누수 없음
- Esc로 언제든 로비. 진행 중 나가면 점수 없음
- vs AI / vs 사람 모두 5개 게임이 실제로 끝까지 플레이 가능
- 주석은 한국어로 핵심만
- 완성 후 index.html을 브라우저에서 열어 로비 → 5게임 × 2모드를 직접 확인할 것. 스크린샷만 찍고 끝내지 말 것
