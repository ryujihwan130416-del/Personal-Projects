# 사이트폴

Unity 6.3 LTS용 1인칭 게임입니다. 캐릭터, 총, 단검, 맵, 걷기·사격·찌르기·설치 동작은 플레이할 때 코드가 직접 만듭니다. 사람 한 명이 방을 열면 그 컴퓨터가 호스트가 되고, 빈자리는 AI가 채웁니다.

## 열기

1. Unity Hub에서 **Unity 6.3 LTS**를 설치합니다.
2. 이 `Sitefall` 폴더를 프로젝트로 엽니다.
3. 스크립트 컴파일이 끝나면 메뉴 **사이트폴 → 프리팹 준비**가 자동으로 네트워크 프리팹을 만듭니다.
4. `Assets/Scenes/Main.unity`를 열고 Play를 누릅니다.

## 모드

- **사냥:** 킬러 1, 시민 10. 체력 150. 소총은 머리 100, 몸 50, 다리 25. 시민 단검은 대상의 등 120도, 1.4m 안에서 150, 그 밖 근접은 60. 시민이 모두 죽으면 킬러 승. 킬러가 죽거나 4분이 지나면 시민 승.
- **섬멸:** 5대 5. 라운드 중 부활 없음. 상대 전멸이 라운드 승. 5라운드 선취.
- **신호 설치:** 5대 5, 사이트 A/B. 라운드 100초, 설치 4초, 해제 7초, 폭발 45초. 4라운드 후 공수 교대. 5라운드 선취.

메인 메뉴에서 **방 만들기**를 누르면 UDP `7777`로 열립니다. 다른 사람은 호스트의 IP를 입력하고 **참가**합니다. 방 주소는 호스트 화면 상태에 표시됩니다.

## 빌드

Unity 메뉴의 **사이트폴 → Linux 빌드** 또는 **사이트폴 → Windows 빌드**. Windows 빌드는 Windows Build Support 모듈이 필요합니다.

클라우드에서 Unity 6.3.24f1 Linux 에디터를 받아 빌드를 시도했습니다. 이 머신에는 Unity 라이선스가 없어 `No valid Unity Editor license found`에서 멈췄습니다. 실행 파일은 Unity Hub에 로그인한 PC에서 위 메뉴로 만듭니다.
