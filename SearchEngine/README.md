# 서랍

로컬 전용 미니 웹 검색 엔진입니다. 퍼블리시하지 않고 내 컴퓨터에서만 씁니다.

지정한 URL을 크롤해 색인한 뒤, 브라우저에서 검색합니다. 처음 실행하면 샘플 문서 4개가 들어가 있어 바로 검색해 볼 수 있습니다.

## 여는 법

```bash
cd SearchEngine
python3 -m pip install -r requirements.txt
python3 server.py
```

브라우저에서 [http://127.0.0.1:8765](http://127.0.0.1:8765) 를 엽니다.

## 쓰는 법

1. 검색창에 단어를 넣습니다. 예: `녹차`, `BM25`, `남산`
2. 아래 **페이지 모으기**에 시작 URL을 넣고 크롤합니다.
3. 같은 사이트 안 링크를 따라가며 색인에 더합니다.
4. **샘플 문서로 초기화**로 다시 시작할 수 있습니다.

## 동작

| 단계 | 내용 |
| --- | --- |
| 크롤 | robots.txt 확인, 요청 간격, 깊이·개수 제한 |
| 파싱 | 제목·본문·링크 추출 |
| 색인 | 역색인(단어 → 문서) |
| 검색 | BM25 점수 + 스니펫 |

색인은 `data/corpus.json`에 저장됩니다. 이 폴더는 git에 올리지 않습니다.

## API

- `GET /api/search?q=녹차`
- `GET /api/health`
- `POST /api/crawl` — `{ "seeds": ["https://example.com"], "max_pages": 20, "max_depth": 1 }`
- `POST /api/reset` — `{ "use_fixtures": true }`

## 범위

- 로컬(`127.0.0.1`)에서만 서버를 엽니다.
- 인터넷 전체가 아니라, 내가 넣은 URL 주변만 모읍니다.
- 한국어는 공백·구두점 기준 토큰(2글자 이상)으로 나눕니다.
